4. **Contacts**: Contact list access for speed dialing and emergency contacts.
5. **Call / SMS**: Direct phone dialer and SMS composition intent dispatch.
6. **Storage**: All files access and full memory/notes export to file.
7. **Accessibility Service**: Hands-free navigation and vocal accessibility announcements.

10. **Screen Capture (MediaProjection)**: Real-time on-screen inspection and contextual UI reading.
11. **Battery Optimization Ignore**: Screen Wake Lock and 24/7 background standby.
12. **Auto-Start on Boot**: Boot completed broadcast receiver for automatic initialization.
